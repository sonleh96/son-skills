# Statechart activation

This update activates Pstack's `statechart` at the accepted Pstack pin `1ba91fc25c0977741dd0e267849e6234b037ed0a`.
The pin, the snapshot, and the other skills are unchanged from the [October 29 adoption](2026-10-29.md).
The activation script is `.local/activate-statechart-20261031/activate.py`.
It reuses the October 29 `import_skill` adapter.

## What changed

`statechart` moves from the excluded list to an active, explicit-only skill in the verification category.
It runs only when called as `/statechart`, and its Codex metadata disables implicit invocation.
The adapter adds the Son compatibility line to `SKILL.md`, the `SON-COMPATIBILITY.md` link, the Codex metadata, and the Pstack license.
Every other file of the 407-file original is byte-identical, and the `scripts/statechart` launcher keeps its executable mode.
The `imported_files` baseline in `stack.json` describes this clean adapted copy, so the skill has no local edits.

## Dependencies

Activation installs no tools.
The launcher needs Node 22.18 to 22.x, Node 23.6 or later, Bun 1.1.5 or later, or Deno 2.0 or later.
On its first run, the checker installs Java and `tla2tools.jar` 1.7.4 through `mise` and needs the network.
Without `mise`, the run fails with an error that names `TLA2TOOLS` and `JAVA` as the manual alternative.
Rendering a chart as SVG needs the npm package `pele@1.9.0`; the Mermaid text needs nothing extra.
Son compatibility still applies: installing any of these is a separate action under the active task's authority.
