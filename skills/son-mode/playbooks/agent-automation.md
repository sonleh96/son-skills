# Agent automation

Read Son compatibility before this playbook.

Use `automate-me` to identify repeatable work from actual usage.
Use `design-control-loop` for the control model and `build-iterated-agentic-loop` for an authorized implementation.
Choose `create-verification-skill` or `maintain-verification-skill` according to whether verification already exists.
Schedule only through the active application's supported scheduler when the user requests a cadence.
