# Motion design

Read Son compatibility before this playbook.

Use `animation-vocabulary` to establish terminology only when needed.
Use `find-animation-opportunities` for an existing interface, then `animate` or `animate-expo` for the target platform.
Use `animation-performance` when web motion stutters or drops frames, then verify its cause with a recording.
Use `review-animations` to assess the result and `improve-animations` for a requested revision.
Inspect reduced-motion behavior and keyboard interaction in the rendered application.
