# Fresh-context routing

Several Matt skills ask for a fresh context window for each delegated agent.

Carry the complete brief into the new context: Son's policies, the selected playbook and skill, repository and owned paths, the task boundary, the selected model and supported effort, and the required evidence.

In Codex, `fork_turns="none"` is the native control for a fresh child context when the active capability exposes it.
Use the active application's equivalent when one exists.

If no fresh-context control is available, report that limitation and preserve the native `son-agent` route.
Do not silently reuse the parent context, substitute a model, or remove an independent reviewer from the workflow.

When the same selected skill is already running inside `son-agent`, execute it directly instead of redispatching it or creating a nested specialist route.
This does not prohibit the creator workflow from dispatching its authorized stage-specific implementer, explorer, or independent reviewer agents.
